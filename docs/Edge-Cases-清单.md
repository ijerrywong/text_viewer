# Edge Cases 全清单（边界情况）

> 每个条目：**场景 → 影响 → 处理策略 → 优先级(P0 阻塞上线 / P1 尽量 / P2 可选) → 归属阶段**。
> 优先级总原则：**隐私与安全 > 不崩溃 > 可用性 > 体验**。

---

## A. 文件获取（Intake）

| # | 场景 | 影响 | 处理策略 | 优先级 | 阶段 |
|---|---|---|---|---|---|
| A1 | 用户取消 `chooseMessageFile` | 空页面 | 忽略 cancel，停留首页并给出引导文案 | P0 | M1 |
| A2 | 一次选多个文件 | 阅读态混乱 | 文件队列 + 顶栏标签/抽屉切换，记住每个文件进度 | P1 | M2 |
| A3 | 文件名为空/超长/纯 emoji/含 `../` `:` `*` `?` | 落盘失败或安全 | 文件名清洗：取合法部分、截断、空名回退为"未命名.txt"，一律以 `stableId` 作磁盘名 | P0 | M1 |
| A4 | 扩展名与实际内容不符（.txt 实为 md、.html 实为 txt、无扩展名） | 解析器选错 | **内容嗅探优先于扩展名**：魔数 + 关键字（`#`/`<!DOCTYPE`/`<html`）打分 | P0 | M1 |
| A5 | 大小写/多后缀扩展名 `.TXT` `.Markdown` `.HTML` `.tar.gz.txt` | 识别失败 | 扩展名归一化小写 + 取最后一段 + 内容嗅探兜底 | P1 | M1 |
| A6 | 「用小程序打开文件」场景：不同微信版本/机型，文件字节获取方式与场景值差异 | 核心入口失效 | Intake 抽象；主入口 `chooseMessageFile` 兜底；构建期按官方文档核对清单逐条真机验证 | P0 | M1 |
| A7 | `tempFilePath` 失效（会话切换/被清理）后再读 | 打开失败 | 拿到文件立即复制到 `USER_DATA_PATH`，之后只读本地副本 | P0 | M1 |
| A8 | 冷启动 vs 热启动（`onLaunch`/`onShow` 重复触发、二次进入） | 重复加载/丢文件 | 场景与文件 id 去重；`onShow` 幂等，避免重复初始化 | P1 | M1 |
| A9 | 从分享/参数进入（带 `path`/`query`） | 打不开 | 解析参数，非法参数回首页，不崩溃 | P1 | M2 |
| A10 | 文件来自不同来源（收藏、文件传输助手、群聊、订阅号） | 权限/类型差异 | 统一按"普通文件"处理，不依赖来源 | P1 | M1 |

## B. 编码与字符

| # | 场景 | 影响 | 处理策略 | 优先级 | 阶段 |
|---|---|---|---|---|---|
| B1 | UTF-8 无 BOM（最常见） | — | 默认路径 | P0 | M1 |
| B2 | UTF-8 带 BOM（EF BB BF） | 首字符出现 `\ufeff` | 剥 BOM | P0 | M1 |
| B3 | GBK / GB2312 / GB18030（大陆 txt 常态） | 整篇乱码 | 内置 GB18030 解码 + 启发式识别 | P0 | M1 |
| B4 | Big5（繁体） | 乱码 | 内置 Big5 解码 + 手动切换 | P1 | M2 |
| B5 | UTF-16 LE/BE（有 BOM FF FE / FE FF） | 乱码 | BOM 识别 + UTF-16 解码 | P1 | M2 |
| B6 | 无 BOM 的 UTF-16 | 探测难 | 字节启发式（高频 `00`）+ 手动切换兜底 | P2 | M3 |
| B7 | 混合编码/半角乱码/截断字节 | 局部乱码 | 检测失败时不崩溃，局部替换 `\uFFFD`；提供手动切换 | P1 | M2 |
| B8 | 空文件（0 字节） | 白屏 | 明确提示"空文件"，不报错 | P0 | M1 |
| B9 | 只有空白/换行 | 看似空白 | 提示"无可见内容" | P2 | M2 |
| B10 | 编码探测误判 | 大面积乱码 | **手动编码切换入口**（顶部胶囊），切换后重解析 | P0 | M1 |
| B11 | emoji / CJK 扩展区 / 组合字符 / RTL（阿拉伯、希伯来） | 渲染异常/方向错 | 渲染层兼容：不截断代理对、RTL 段落方向标记 | P1 | M2 |
| B12 | 行尾 CRLF / LF / CR 混杂 | 多余空行/粘连 | 归一化行尾 | P0 | M1 |
| B13 | 超长单行（minified JSON/HTML 一行几 MB） | 渲染/正则爆炸 | 单行超阈值截断展示 + 提示；避免行级正则全文处理 | P0 | M3 |
| B14 | NUL 字节 / 二进制伪装成 .txt | 乱码/崩溃 | 二进制检测（NUL 占比、无效 UTF-8 占比 >30%）→ 判"不支持/二进制" | P1 | M2 |
| B15 | HTML 内 `<meta charset="gbk">` 与实际编码 | 误判乱码 | **`<meta charset>` 优先级仅次于 BOM**，高于字节启发式——这是比猜测可靠得多的显式信号 | P0 | M3 |
| B16 | 零宽字符（`​` `﻿`）夹在行首 | Markdown 标记失效（如 `#​ 标题` 不识别为标题） | 解析前清洗行首行尾零宽字符（正文中的合理用法需保留，故不做全文清洗） | P1 | M2 |
| B17 | 期望用 `TextDecoder` 解 GBK | 实现走死路 | ⚠️ **小程序不提供 `TextDecoder` 全局对象**（不是"支持不稳定"，是根本没有）。不要写特性检测分支，直接内置码表自实现 | P0 | M1 |

## C. 格式与解析

| # | 场景 | 影响 | 处理策略 | 优先级 | 阶段 |
|---|---|---|---|---|---|
| C1 | Markdown 方言差异（GFM 表格/任务列表/脚注） | 部分不渲染 | 目标支持 GFM 子集；不支持语法降级为纯文本不丢内容 | P1 | M2 |
| C2 | 不规范的 Markdown（未闭合、嵌套错、裸 HTML 内嵌） | 解析错乱/卡死 | 解析器容错 + try/catch 隔离 + 兜底按纯文本 | P0 | M2 |
| C3 | 数学公式 `$…$` / `$$…$$` | 显示成源码 | 可选 KaTeX 适配（小程序有社区方案）；未开启时原文显示 | P2 | M3 |
| C4 | 代码块未知语言/无语言 | 高亮缺失 | 按纯文本代码块，保留缩进、横向滚动 | P1 | M2 |
| C5 | 超宽表格 | 溢出屏幕 | 表格容器横向滚动 + 最小列宽 | P1 | M2 |
| C6 | 深层嵌套列表（>10 层） | 布局撑爆 | 深度上限，超出折叠 | P2 | M2 |
| C7 | HTML 是片段（无 `<html>/<body>`） | 解析失败 | 容错为片段解析，自动补容器 | P0 | M3 |
| C8 | HTML 内联 CSS / `<style>` 块 | 样式丢失 | 解析 `<style>` 提权为内联样式（子集）| P1 | M3 |
| C9 | HTML 相对路径资源（`src="a.png"`）已丢失 | 破图 | 占位图标 + "资源缺失"提示，不报错 | P1 | M3 |
| C10 | HTML 含超大 base64 图片 | 内存/卡顿 | ADR-8：抽取落盘、单图/总量阈值、懒加载、占位 | P0 | M3 |
| C11 | HTML 含 `script/iframe/form/on*` | 安全 | ADR-6 强制消毒剥离 | P0 | M3 |
| C12 | HTML 实体错误 / 未闭合标签 | 解析错乱 | 容错解析，try/catch 隔离，坏块降级纯文本 | P1 | M3 |
| C13 | `.mhtml`（MIME 包裹单文件） | 无法直接渲染 | 识别并提示"暂不支持 mhtml"，可规划解包 | P2 | — |
| C14 | `.docx/.pdf/.pptx/.xlsx` | 渲染不了 | 引导用 `wx.openDocument`（微信原生预览）或提示不支持 | P1 | M4 |
| C15 | 压缩包内文本（.zip/.7z） | 打不开 | 明确提示"请解压后发送" | P2 | M4 |
| C16 | JSON / CSV / XML / log / 源码 | 一行糊 | 基础美化：JSON 折叠树、CSV 表格、代码等宽字体 + 语法色（可选） | P2 | M3 |
| **C17** | **HTML 引用 `cdn.tailwindcss.com`，只写类名不写 CSS** | **⚠️ 样式全部归零，精美文档塌成一堆左对齐裸文本——AI 生成 HTML 的最高频失败模式** | **内置 Tailwind 类名规则生成器**（正则解析 `p-4`/`bg-slate-50`/`grid-cols-3` 等模式，非穷举表，~20KB），检测到 Tailwind 时异步加载（ADR-10） | **P0** | M3 |
| C18 | HTML 用 CSS 变量 `:root{--primary:…}` + `var()` | 配色全丢 | 单层收集 `:root` 与节点自定义属性，自顶向下继承后替换 `var()` | P0 | M3 |
| C19 | 依赖 `::before`/`::after` 做图标、引号、序号装饰 | 装饰全丢，视觉降级明显 | 把 `content` 合成为真实子节点插入首/尾（inline style 无法表达伪元素） | P1 | M3 |
| C20 | 桌面宽度假设 `max-width:1200px; margin:0 auto` | 手机上横向溢出、页面可左右拖动 | 注入优先级最低的兜底 `*{max-width:100%;box-sizing:border-box}` + 钳制根容器固定宽度。**`px` 不换算**（小程序 px 即逻辑像素） | P0 | M3 |
| C21 | `position:fixed` / `sticky` 侧边栏、悬浮目录 | 遮挡正文或定位错乱 | 降级为 `static` 回到文档流；对目录类内容回流反而更合理 | P1 | M3 |
| C22 | 含 Chart.js / ECharts / D3 图表 | 只剩空白 `<canvas>` div | 占位卡片 +"图表无法在小程序中显示"+ 保留邻近说明文本。**降级必须可见** | P1 | M3 |
| C23 | reveal.js / impress.js 幻灯片 HTML | 全部堆叠或只显示第一页 | **每个 `<section>` 渲染为一张竖排卡片，幻灯片流式化**（含嵌套 section 的纵向幻灯片） | P1 | M3 |
| C24 | Markdown Front-matter（YAML 头） | 渲染成分割线 + 乱码文本 | 识别并剥离，可选用 `title` 作文档标题 | P1 | M2 |
| C25 | 未闭合的代码围栏 ``` | 后半篇全变代码块 | 解析器默认"到文末为止"可接受；超长代码块（>2000 行）提示"可能是未闭合的代码块" | P2 | M2 |
| C26 | 内联 SVG 图标/图表 | 小程序不支持内联 SVG 节点 | 转 `data:image/svg+xml;base64` 交给 `<image>` 组件——可行且价值高 | P2 | M3 |

## D. 渲染与性能

| # | 场景 | 影响 | 处理策略 | 优先级 | 阶段 |
|---|---|---|---|---|---|
| D1 | 大文件 10MB/50MB/100MB | 崩溃/卡死 | ADR-5 分层：分块读、Worker 解析、渐进渲染、>50MB 降级分页 | P0 | M3/M4 |
| D2 | 长文档滚动掉帧 | 卡顿 | 虚拟滚动 + 固定/预估行高 + 复用节点 | P0 | M3 |
| D3 | 多图大图 | 内存爆 | 懒加载、占位、LRU 释放、单图阈值跳过 | P0 | M3 |
| D4 | 深色/护眼主题切换 | 闪烁 | 主题 token 化，切换不重解析只重渲染 | P1 | M1 |
| D5 | 字体缺失（中文衬线阅读体） | 观感差 | 系统字体回退栈；可选内置阅读字体(体积权衡) | P2 | M2 |
| D6 | 小屏溢出（代码/表格/长 URL） | 撑破布局 | 容器 `overflow` 横向滚动 + 断词策略 | P0 | M2 |
| D7 | 目录锚点跳转 | 跳不到 | IR heading 生成 id，滚动定位 + 高亮当前标题 | P1 | M2 |
| D8 | 大文档全文搜索 | 卡顿 | 增量索引/分块搜索 + 结果高亮 + 取消旧搜索 | P1 | M3 |
| D9 | 低端机（旧安卓、内存小）崩溃 | 差评 | 分块 + 降级 + 真机低端机测试门禁 | P0 | M4 |
| D10 | iOS vs Android `rich-text` 渲染差异 | 观感不一致 | 用统一 IR + 受控组件，减少对 rich-text 复杂特性依赖；真机双端回归 | P0 | M4 |
| D11 | 切后台再回来状态丢失 | 体验差 | `onHide` 持久化进度，`onShow` 恢复。**不要依赖 `onUnload`**（小程序被系统清理时不触发） | P0 | M1 |
| **D12** | **单次 `setData` 超 1MB** | **内容不显示，控制台报数据过大** | 单次下发控制在 ~64KB；按块分批；用路径写法局部更新；节点树剔除渲染不需要的字段（原始文本、AST 元信息）；base64 图片落盘换路径（ADR-8） | **P0** | M2 |
| **D13** | **虚拟滚动高度回填导致页面猛跳** | **向上滚动时页面突跳，难复现难定位** | 修改**已渲染区域上方**块高度时，**必须同步反向调整 `scrollTop` 做补偿**。这是虚拟滚动最容易做砸的一点，需专项测试 | **P0** | M2 |
| **D14** | **在 Worker 里调 `wx.getFileSystemManager()`** | **报错，实现卡死** | Worker 内**无文件系统 API**。主线程读文件并解码 → `postMessage` 传字符串 → Worker 纯计算解析 → 分批回传（每批 ~50 Block） | **P0** | M2 |
| D15 | 快速滑动时来不及渲染 | 白屏闪烁 | 预渲染缓冲区 ±2 屏；缓冲区外显示**带预估高度的骨架块**而非纯空白 | P1 | M2 |
| D16 | 网络图片加载完成后高度变化 | 滚动跳动 | `bindload` 拿到真实尺寸后更新块高并做 D13 的滚动补偿 | P1 | M3 |
| D17 | 图片加载失败导致布局塌陷 | 滚动偏移错乱 | `<image>` 预设占位高度，`binderror` 时替换内容但**不改变块高** | P0 | M2 |
| D18 | 主线程解析大文件卡死数秒 | 用户以为崩了 | 解析全放 Worker + 进度上报；Worker 不可用（低版本/异常）降级为 `setTimeout` 分片解析 | P0 | M2 |
| D19 | Worker 代码包超 2MB | 无法构建 | 码表不打包进 Worker，由主线程 postMessage 传入 | P1 | M2 |
| D20 | 长时间阅读多文档后闪退 | 内存累积 | 切换文档时释放上一份 AST 与节点缓存；滑过很远的块只保留高度 | P2 | M4 |

## E. 交互与状态

| # | 场景 | 影响 | 处理策略 | 优先级 | 阶段 |
|---|---|---|---|---|---|
| E1 | 阅读进度（位置 + 上次文件） | 找不到上次位置 | 滚动节流保存 **`{fileId, blockIndex, ratio}`（块索引 + 块内比例）**。⚠️ **绝不存 `scrollTop` 像素值**——字号/行距/主题一变像素位置即失效，虚拟滚动下块高还会动态修正（ADR-11） | P0 | M1 |
| E1b | 字号/行距/主题变更后进度失效 | 跳回错误位置 | 进度基于块索引则天然免疫；变更后清空已测高度缓存并重新预估 | P0 | M2 |
| E1c | 从中间位置恢复进度 | 上方块未渲染过，不知总高 | 直接跳到块索引，用预估高度构建上方占位，滚动时逐步修正 | P0 | M2 |
| E2 | 横竖屏切换 | 布局错乱 | 响应式/重算视口，保持当前位置 | P1 | M2 |
| E3 | 分享转发 | 分享链接而非文件 | 明确分享语义（引导对方"用小程序打开该文件"，或复制文本） | P1 | M3 |
| E4 | 复制文本/代码 | 失败 | `wx.setClipboardData`；大段文本分次/提示 | P1 | M2 |
| E5 | 系统字体放大（无障碍） | 重叠/截断 | 相对单位 + 上限 + 可滚动 | P2 | M4 |
| E6 | 连续阅读多文件 | 进度串味 | 进度按 fileId 隔离 | P1 | M2 |
| E7 | 设置持久化（主题/字号） | 每次重设 | `settings` 落盘，启动读取 | P0 | M1 |
| **E8** | **剪贴板为空 / 非文本 / 超长（几十万字）** | 空白页或卡死 | 空则提示"剪贴板里没有文本内容"；超长走与文件相同的分块管线，不可直接 setData | **P0** | M1 |
| **E9** | **iOS 读剪贴板弹出"XX 读取了你的剪贴板"** | 用户警觉、体验受损 | **仅在用户明确点击「粘贴」时读取，绝不静默读取**；按钮旁标注"仅读取一次，不会上传" | **P0** | M1 |
| E10 | 粘贴内容含敏感信息被无意持久化 | 隐私 | 粘贴内容默认**不落盘**，仅存于本次会话；另给显式「保存到最近」动作 | P1 | M1 |
| E11 | 深色模式下 HTML 自带 `background:#fff` | 刺眼白纸块 | 强制深色算法：反转亮度分量、保留色相与饱和度，图片不处理。**必须可一键关闭**（用户可能就想看原色） | P1 | M3 |
| E12 | 文档内链接点击无反应 | 用户困惑 | 弹窗显示完整 URL + 「复制链接」+ 说明"请在浏览器中打开"（小程序无法跳转外部浏览器） | P0 | M2 |
| E13 | 长按选中文本影响滚动手势 | 滚动失灵 | `text` 组件加 `user-select` 后需真机调试手势冲突 | P2 | M2 |
| E14 | 阅读时屏幕自动熄灭 | 体验差 | 阅读页 `wx.setKeepScreenOn(true)`，退出时关闭 | P2 | M2 |

## F. 安全与合规

| # | 场景 | 影响 | 处理策略 | 优先级 | 阶段 |
|---|---|---|---|---|---|
| F1 | 钓鱼 HTML（仿登录页、诱导点击外链） | 安全/投诉 | ADR-6 消毒 + 外链点击→确认→复制，绝不静默跳转 | P0 | M3 |
| F2 | 恶意超大/压缩炸弹 HTML | 卡死 | 体积/块数上限，超限降级纯文本或提示 | P1 | M4 |
| F3 | 文档隐私（本地文件） | 信任 | 零后端设计本身保证；隐私声明明示"文件不上传" | P0 | M4 |
| F4 | 外链域名白名单（若未来用图片外链/web-view） | 审核风险 | MVP 不加载任何外链资源，无此问题 | P1 | — |
