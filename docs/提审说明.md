## 功能简介

一个纯本地、零后端的微信小程序，在微信里查看 HTML / Markdown / TXT 等纯文本文件。

### 核心功能

1. **文件查看**：支持 TXT / Markdown / HTML / JSON / CSV / 日志 / 源码等纯文本格式
2. **编码识别**：自动识别 UTF-8 / GBK / GB18030 / Big5 / UTF-16 等编码，支持手动切换
3. **Markdown 渲染**：支持 GFM 表格、任务列表、代码高亮、目录跳转、全文搜索
4. **HTML 渲染**：支持 Tailwind 类名展开、CSS 变量求值、伪元素合成、视口钳制、脚本降级可见化
5. **阅读体验**：虚拟滚动、字号/行距/字体调节、浅色/深色/护眼主题、阅读进度保存
6. **安全消毒**：剥离 script/iframe/on* 事件等危险内容，外链点击→确认→复制

### 三个入口

| 入口 | 说明 |
|---|---|
| 从聊天选择文件 | 通过 `wx.chooseMessageFile` 从聊天会话选文件 |
| 粘贴文本 | 从剪贴板粘贴 Markdown / 纯文本内容 |
| 查看示例 | 内置 Markdown / HTML / TXT 三份示例文档 |

## 隐私声明

> 完整口径见 **`docs/隐私说明.md`**（含后台《用户隐私保护指引》可直接填入的正文、
> 完整数据清单、以及每条承诺对应的代码位置）。此处为提审用摘要。

**本小程序所有文件均在用户的手机本地解析渲染，全程不上传任何服务器，无云端存储、无文件分享功能。**

### 收集的信息

| 信息类型 | 接口 | 用途 |
|---|---|---|
| 你选中的文件 | `wx.chooseMessageFile` | 从聊天会话中选取用户指定的文件进行本地解析渲染 |
| 读取你的剪切板 | `wx.getClipboardData` / `wx.setClipboardData` | 用户主动点击「粘贴」时读取一次剪贴板文本；复制链接/代码时写入剪贴板 |

> 关于「收集」这个措辞：微信的隐私声明按**接口**管，声明的是"有能力接触到这类数据"，
> 不是"会把它传走"。本小程序的文件副本只存在于本机小程序沙盒中。详见 `docs/隐私说明.md` §1。

### 信息处理方式

- 所有文件内容仅在设备本地处理，解析、渲染、存储全部在小程序内完成
- 不收集、不上传、不分享任何用户数据
- **粘贴的剪贴板内容默认不写入存储**，仅存在于本次阅读会话的内存中；
  需要保留时由用户点击「保存到最近」显式决定
- 文件可由用户随时在「设置 - 清除缓存」中删除（该页同时显示当前缓存占用）
- 阅读进度和设置仅存储在本地小程序存储中，不含正文内容
- **网络图片默认关闭**，开关旁明示"可能泄露 IP 与阅读行为"

## supportedMaterials 声明

```json
"supportedMaterials": [
  {
    "materialType": "text/html",
    "name": "用${nickname}打开",
    "desc": "渲染HTML文档，支持Tailwind样式",
    "path": "pages/index/index"
  },
  {
    "materialType": "text/plain",
    "name": "用${nickname}阅读",
    "desc": "自动识别GBK等中文编码",
    "path": "pages/index/index"
  }
]
```

### 声明理由

- **text/html**：本小程序能展开 Tailwind 类名、求值 CSS 变量、合成伪元素，提供微信原生无法实现的 HTML 渲染能力
- **text/plain**：本小程序能自动识别 GBK/GB18030/Big5 等中文编码，提供微信原生 txt 查看器无法实现的编码识别能力
- **text/markdown**：不在微信 supportedMaterials 支持列表中，用户通过「从聊天选择文件」入口打开
