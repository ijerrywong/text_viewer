## 审计修复记录（2026-08-15）

本次上线前审计修复了以下问题：

1. **app.js handleLaunchScene 重复导航**：onShow 中重复调用导致 scene 1173 可能重复跳转。添加 `_scene1173Handled` 标志确保幂等。
2. **store/index.js LRU 目录大小计算错误**：`statSync` 对目录返回目录条目大小而非内容总大小。新增 `getDirSizeSync` 递归计算，`lruClean` 和 `getFileDirSize` 均改用此函数。
3. **reader.js onImageError 死代码**：原实现设置了 `this['_imgError_' + idx]` 但从未使用。改为在 `_blocks` 上标记 `_imgError`，WXML 添加「图片加载失败」占位显示。
4. **index.js 过期 TODO 注释**：移除 `viewSamples` 方法中的 `// TODO Phase 1` 注释（示例文档已实现）。
5. **reader.js `_measureTimer` 未声明**：补充到内部状态声明区域。
